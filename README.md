# AviaFly — языковые версии

Копия публичных клиентских файлов игры с https://aviajdsfkjsfd.vercel.app/ и четырьмя дополнительными языками: польским (`pl`), сербским латиницей (`sr`), чешским (`cs`) и итальянским (`it`). Оригинальные русский, английский и испанский доступны в переключателе.

Язык выбирается на экране загрузки или в настройках игры. Выбор сохраняется в браузере. Прямая ссылка с параметром `?lang=pl`, `?lang=sr`, `?lang=cs` или `?lang=it` открывает нужную версию.

Переведены загрузка, настройки, правила, автозапуск, сообщения, названия выигрышей и портал. Выбор языка не меняет валюту и баланс.

## Локальный запуск

Требуется Node.js 20 или новее. Внешние пакеты не нужны.

```sh
npm start
```

Откройте http://127.0.0.1:3010/ . Другой порт задаётся переменной окружения `PORT`. Для публикации также подходит статический хостинг, в том числе GitHub Pages.

## Редактирование переводов

Тексты находятся в `locales/*.json`, общая логика — в `i18n-runtime.js`. После изменений:

```sh
npm run build
npm test
```

Команда сборки обновляет `avia-i18n.js`. Этот файл включён в репозиторий, поэтому опубликованная игра запускается без сборки.

## Состав копии

- `index.html` — страница запуска.
- `avia-game.js` — публичная сборка основного игрового клиента.
- `avia-local.js` — поставляемая оригиналом локальная модель игры и виртуальный кошелёк.
- `avia-loader.js` — экран загрузки.
- `avia-portal.js` — встроенная игра портала.
- `avia-assets-1.js` … `avia-assets-3.js` — 349 встроенных ресурсов, включая изображения, модели, звуки и шрифты.
- `DOWNLOAD-MANIFEST.json` — источник и контрольные суммы скачанных оригиналов.
- `server.js` — небольшой HTTP-сервер на Node.js.

Это скачанные публичные файлы и их изменения. Приватный репозиторий, исходники до сборки и серверная инфраструктура исходного сайта через публичный адрес недоступны. Сама исходная версия работает с локальной моделью и виртуальным балансом браузера; они сохранены. Историю оригинальной копии можно найти в первом коммите репозитория.

## Проверка

Автоматические тесты проверяют четыре перевода, приоритет параметра URL над сохранённым языком, генерацию словарей игрового движка и выдачу клиентских файлов сервером. Дополнительно проверены запуск и экраны настроек в браузере.
